01 · The problem

Most benchmark tasks are wasted money.

To test an AI coding agent you need tasks it actually fails. Today the only way to find one is to build it, check it, pay for the model runs, and hope. Most of the time the agent solves it, and the work teaches you nothing.

  • 01Building a task is slow. A real vulnerability, a Docker image, hidden tests, a fairness review.
  • 02Running it costs money. Every attempt by every model is a paid API call.
  • 03Most get solved. A strong agent fixes the obvious vulnerability, and the task is thrown away.

04 · How it works

A loop that gets smarter every time it runs.

Vanguard turns that research into a machine. It ranks real vulnerabilities, builds the most promising ones into tasks, checks they are fair, runs the models, and feeds every result back into the graph.

STAGE 1

🧠 Knowledge Graph

Remembers every task, run and outcome, and learns which weaknesses beat which model.

knowledge_graph.py · learner.py
STAGE 2

🔎 Harvester

Pulls real security fixes from GitHub and scores each one's chance of beating each model.

harvester.py · rank
STAGE 3

🛠️ Synthesizer

An AI agent turns the best candidates into sealed Docker tasks. A person approves each one.

loop.py
STAGE 4

⚖️ Judge

Proves each task is fair, runs the models behind budgets, and sends results back.

validate.py · collect

06 · It learns

Every result makes the next prediction better.

We test the predictor the hard way: hide an entire repository, train on the rest, and score its predictions on the hidden one. The Brier score measures how far predictions land from reality (lower is better).

07 · The Judge

No unfair task gets through. No money moves without you.

A task is only useful if failing it means the model really failed. Before any model runs, every task has to prove it is fair, automatically.

Gate 1You approve each built task before it is validated.
Gate 2You approve more attempts only after both models fail round one.
